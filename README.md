# College Event Management System

## About the Project
The College Event Management System is a Java-based application developed using Java Swing.

## Features
- Add college events
- View available events
- Register for events
- Manage event information

## Technologies Used
- Java
- Java Swing
- VS Code

## Project Structure
- Event.java
- EventGUI.java
- EventManager.java
- Main.java
- Registration.java

## Team Project
This project was developed as a mini project by a team of 5 students.
